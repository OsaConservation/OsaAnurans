Get newer annotations
  1. In the PowerShell window running the annotation browser, press Ctrl+C to stop it.
  2. Go to the repository folder:
    cd C:\OsaAnurans
  3. Fetch the latest annotations using the app's Python:
    .\osa_anurans_app\.venv\Scripts\python.exe -m osa_anurans_app.src.cli refresh
  4. When the refresh finishes, restart the annotation browser:
    .\osa_anurans_app\.venv\Scripts\python.exe -m osa_anurans_app.src.cli browse
  5. Open the local URL printed in PowerShell to see the refreshed annotations.

Reloading this page alone does not fetch newer annotations. These commands use the app's environment directly, so you do not need to activate it.
